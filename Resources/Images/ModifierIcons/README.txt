MODIFIER ICONS FOR THE STRATEGY INFO WINDOW
============================================================

Put one PNG per modifier in this folder. The Strategy Info window shows all 12 as
6 x 2 squares: a modifier the strategy uses is shown in colour, one it does not use
is shown in grayscale. Hover a square to see the modifier's name.

FORMAT
  - PNG, named exactly as in the list below (capitals included).
  - Square images. The squares are about 62 x 62 pixels, so 128 x 128 or 256 x 256 is plenty.
    Images that are not square keep their proportions and are centred.
  - <Name>.png is the colour image, shown when the strategy uses the modifier.
  - <Name>_Gray.png is the grayscale image, shown when it does not. If a _Gray file is missing, the macro
    makes the grayscale version itself from the colour image.
  - A modifier without a file is not an error: its square shows the short code instead.
  - Reopen the Info window after adding files (no restart needed).

THE 12 MODIFIERS  (file name, short code used in the strat file, name shown on hover)
  Glass.png          Gla   Glass
  Hidden.png         Hid   Hidden Enemies
  Exploding.png      Exp   Exploding Enemies
  Limitation.png     Lim   Limitation Makes Creativity
  Committed.png      Com   Committed
  Flying.png         Fly   Flying Enemies
  Fog.png            Fog   Fog
  Quarantine.png     Qua   Quarantine
  Inflation.png      Inf   Inflation
  Broke.png          Bro   Broke
