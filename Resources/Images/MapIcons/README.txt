MAP ICONS FOR THE STRATEGY LIBRARY
============================================================

Put one PNG per map in this folder. The strategy library shows it on the
fifth icon plate of every strategy card (to the right of the EXP plate).

FORMAT
  - PNG, named exactly as in the lists below (spaces and capitals included).
  - Square images. The plate is 48 x 48 pixels, so 128 x 128 or 256 x 256 is plenty.
    Non-square images are squeezed to fit, so crop them to a square first.
  - A map without a file is not an error: its plate shows the map's initials.
  - Restart the macro (or press Refresh) after adding files.

NOT TO BE CONFUSED WITH
  Resources\Maps holds the images the macro uses to recognise maps in the game.
  Do not put these icons there, and do not change those files.

SPELLING
  Use the names below even where they look odd ("Forgetten Docks", "Lighthaos"):
  they are the spellings the macro uses. Strat files may use the alternative
  spellings ("Forgotten Docks", "Black Spot", ...); the macro maps them to these names.

SPECIAL MODES  (map = mode, the map exists only in that mode)
  The strat's map= line is ignored for these; the card shows the file below.
  Badlands II.png
  Pizza Party.png
  Polluted Wasteland II.png

MAPS THAT ARE NOT IN THIS LIST
  A strat can name any map. If it is not in lib\MapDatabase.ahk its chip is grey and
  the plate says "Unrated". Add a "Name|Rating" line to MapDatabase.ahk to give it a
  rating colour, and put <Name>.png here to give it a picture.
